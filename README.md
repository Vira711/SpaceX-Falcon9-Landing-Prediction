## Important submission checks
- Upload this folder to a public GitHub repository and paste the actual repository URL into the presentation and report.
- The saved notebooks include historical course outputs. Re-run them in your environment to confirm outputs.
- Do not commit database credentials, API keys, or personal tokens.
- Any synthetic dashboard CSV is deliberately excluded from this package. Use the cleaned, verified course dataset for the live dashboard.
- The dashboard wireframe in the presentation is illustrative, not a screenshot of a live app. Replace it with a screenshot of your running app using verified data.

## Environment
Python 3.x; pandas, numpy, matplotlib, seaborn, scikit-learn, folium, plotly, dash, sqlalchemy as needed by the individual notebooks.
